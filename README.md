# Reporte de seguridad (copia)

El mismo editor de reporte fotográfico que [PTTDIARIO](https://github.com/zettafuego/PTTDIARIO). Este repositorio es la copia anterior.

## Abrir en la PC

Doble clic en `start.bat`.

Abre http://127.0.0.1:8765

Hace falta Python 3, más `python-pptx` y `Pillow` (`requirements.txt`). `server.py` arma el PowerPoint desde `plantilla.pptx`.

Si vas a seguir el proyecto, usa [PTTDIARIO](https://github.com/zettafuego/PTTDIARIO).
